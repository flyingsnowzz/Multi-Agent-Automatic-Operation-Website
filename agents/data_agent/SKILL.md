# 数据Agent (DataAgent)

> 当前正式链路基于 LangGraph；本 Agent 通过 LangGraph 节点或工具调用，不再依赖旧队列 worker。

## Agent概述

数据Agent负责采集、分析和报告网站运营数据，是内容优化决策的数据支撑。

## 核心职责

1. **数据采集** - 采集流量数据、排名数据、用户行为数据
2. **趋势分析** - 分析内容表现趋势，识别异常
3. **报告生成** - 生成日报、周报、月报
4. **优化建议** - 基于数据给出内容优化建议

## 数据来源

| 数据源 | 说明 |
|--------|------|
| Google Analytics | 流量、用户行为 |
| Google Search Console | 排名、点击、展示 |
| 百度统计 | 中文SEO数据 |
| 第三方工具 | Ahrefs、Semrush排名数据 |

## 输出

| 输出项 | 说明 |
|--------|------|
| 原始数据 | 采集的原始数据 |
| 数据报告 | 分析后的报告 |
| 优化建议 | 基于数据的建议 |
| 异常告警 | 发现的异常情况 |
