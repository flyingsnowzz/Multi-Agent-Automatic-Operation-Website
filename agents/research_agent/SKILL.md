# 调研Agent (ResearchAgent)

## Agent概述

调研Agent负责为文章收集和整理素材，是选题到写作之间的桥梁。

## 核心职责

1. **资料收集** - 收集文章所需的背景资料、数据、案例
2. **大纲细化** - 将粗略大纲细化为详细写作大纲
3. **素材整理** - 将收集的素材结构化整理
4. **引用验证** - 验证数据和引用的准确性

## 输入

| 输入项 | 说明 | 来源 |
|--------|------|------|
| 选题信息 | 标题、关键词、内容类型 | 文章评分Agent |
| 调研需求 | 需要收集哪些类型的素材 | 写作Agent请求 |

## 输出

| 输出项 | 说明 |
|--------|------|
| 背景资料 | 相关背景信息 |
| 关键数据 | 文章需要的统计数据 |
| 案例素材 | 案例和故事 |
| 引用来源 | 可引用的权威来源 |
| 详细大纲 | 细化的写作大纲 |
