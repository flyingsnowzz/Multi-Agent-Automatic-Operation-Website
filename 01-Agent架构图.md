**版本**: v2.0 | **更新**: 2026-06-29

## 数据流

```
爬虫系统 (外部) → MySQL (crawler_news_main)
                         │
              ┌──────────▼──────────┐
              │  run_scheduler.py    │
              │  每小时/自适应退避    │
              └──────────┬──────────┘
                         │
              ┌──────────▼──────────┐
              │  run_production.py   │
              │  取文章 → 评分 → 改写 │
              └──────────┬──────────┘
                         │
    ┌────────────────────┼────────────────────┐
    │                    │                    │
┌───▼───┐          ┌─────▼─────┐      ┌──────▼──────┐
│AI 评分 │  80分线   │ Quality   │ 70线 │ 改写链路     │
│DeepSeek│──────────│ 写作质量   │─────│ Research    │

```

## 核心组件

| 组件 | 文件 | 说明 |
|------|------|------|
| 生产调度器 | `scripts/run_scheduler.py` | 每小时自动跑，无新文章指数退避 |
| 生产 Pipeline | `scripts/run_production.py` | 取文章 → AI评分 → Quality → 改写 → 发布 |
| 测试调度器 | `scripts/run_test_schedule.py` | 5分钟×5轮的定时批量测试 |
| AI 评分 | `agents/scoring_agent/` | DeepSeek 百分位法，固定线 80 |
| 质量评分 | `agents/quality_agent/` | 写作质量评分，固定线 70 |
| 改写 | `agents/research_agent/` + `agents/writer_agent/` | Research → Write → 复评 |
| SEO | `agents/seo_agent/` | 关键词 V2，短关键词拆分 |
| 配图 | `agents/image_agent/` | Coze 平台生成 |
| 编辑 | `agents/editor_agent/` | 错别字修正 + 安全审校 |
| CMS | `agents/cms_agent/` | REST API 发布 |

## 分数线

| 层 | 阈值 | 通过率 | 逻辑 |
|---|---|---|---|
| AI 评分 | **80** | ~75% | ≤80 直接淘汰 |
| Quality | **70** | ~35% | ≤70 进入改写链路 |
| 改写复评 | **75** | - | <75 丢弃 |

## 吞吐量

- 纯评分+Quality: ~100 篇/小时
- 含改写完整链路: ~70 篇/小时
- 默认每轮取 50 篇，留有富余
